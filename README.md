# Python Data Validator

A small Python project that validates business records and reports data-quality issues.

## What it demonstrates

- Python functions and data structures
- CSV processing
- Input validation
- Error reporting
- Clean, readable logic
- Basic automated testing
- QA-style problem solving

## Run

```bash
python validator.py sample_data.csv
```

## Test

```bash
python -m unittest test_validator.py
```

## Example checks

- Missing product code
- Invalid quantity
- Negative price
- Invalid status value

## Project purpose

This repository demonstrates practical Python data validation, error detection and software-testing fundamentals using a simple business-data scenario.

No external dependencies are required.
